Projects

🔐 Security Toolkit: A Command-Line Cryptography & Password Suite in C

CCS50 Final ProjectCryptographyData StructuresFile I/O
💻 View on GitHub

"Before you can secure a system, you need to understand the primitives it's built on. I built this toolkit as my CS50 final project to implement classic and practical security mechanisms from scratch in C, with nothing hidden behind a library."

🚩 The Goal

Most security tools treat cryptography and password checking as a black box. I wanted to build every piece myself — cipher logic, password scoring, and file encryption — using only core C, to prove I understand what's actually happening at the byte level.

🛠️ What It Does
1. Caesar Cipher
  • Encrypts and decrypts text
  • Shifts letters by a chosen number
  • Supports upper and lowercase
2. Vigenère Cipher
  • Encrypts and decrypts using a keyword
  • Applies a different shift per letter
3. Password Strength Checker
  • Checks length (8+), case mix, digits, symbols
  • Scores from 0–5 → Weak / Medium / Strong
  • Hash table + linked list of common passwords
  • Rejects weak picks like "password" or "123456"
4. XOR File Encryption
  • Encrypts/decrypts any file type
  • Same key both locks and unlocks the file
  • Works directly on raw bytes
⚙️ Under the Hood

Arrays and strings · functions and parameters · ASCII/character arithmetic · modulo wrap-around · file I/O (fopen, fread, fwrite, fclose) · dynamic memory (malloc, free) · pointers · structs · linked lists · hash tables · XOR bitwise operations.

▶️ Run It
# compile
gcc -o security security.c

# run
./security

Menu: 1) Caesar Cipher   2) Vigenère Cipher   3) Password Strength Checker   4) XOR File Encryption   5) Exit

✅ The Takeaway

This project ties directly into my penetration testing and DevSecOps path — understanding how ciphers, password strength, and file encryption work from the ground up makes it much easier to spot where real-world systems get security wrong.
